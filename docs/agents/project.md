# Project context

## Purpose and maintenance

D&D Agent Skills is a public collection of reusable Dungeons & Dragons agent skills, maintained by Nicola Mustone under the same single-maintainer operating agreement as its source, Agent Skills. Users install packages for monster design and prose transformation. Each package owns its runtime and tool requirements.

The maintainer owns product scope, consequential trade-offs and acceptance. Agents handle routine engineering within approved scope and explain consequential choices in practical terms. No usage targets, service-level commitments or operating budget have been established. Shared tooling or infrastructure needs a current requirement.

## Risks and constraints

- Preserve facts and mechanics when transforming prose; keep player-facing information separate from hidden lore.
- Benchmark and validation checks support monster design but do not establish playtested encounter balance.
- Public examples and artifacts must exclude credentials, private material and unnecessary workstation-specific paths. Existing package runtime assumptions remain intact unless explicitly changed.
- Preserve package license declarations and SRD attribution. The root MIT license does not replace third-party or package-specific terms.
- Copies must retain supporting files. Moving the source repository does not update installed copies.
- Report static checks separately from executed agent walkthroughs, model inference and table playtesting.

[Workflow](workflow.md) owns permissions, delivery, verification, releases and documentation upkeep. [Tracker guidance](issue-tracker.md) owns issue relationships and completion; [labels](triage-labels.md) owns classifications. [CONTEXT.md](../../CONTEXT.md) owns shared package vocabulary.
